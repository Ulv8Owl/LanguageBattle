# Сборка и деплой

Порядок обязателен: база → функции → приложение. Функция, задеплоенная
раньше своей миграции, пишет в несуществующий столбец; APK, собранный
раньше функции, показывает данные, которых сервер ещё не присылает.

```
./tools/deploy_server.sh          # 1. миграции + Edge Functions
./tools/build.sh features         # 2. APK из features + установка на телефон
```

`build.sh` доводит дело до конца сам: собирает, ставит через adb и читает с
телефона обратно `versionName`. Не совпал с собранным — останов.

**Без adb это работает точно так же.** Если adb не установлен или телефон не
подключён, скрипт кладёт рядом копию с номером сборки в имени —
`build/chrolingo-<коммит>.apk`, — и печатает, как проверить версию с самого
телефона (Настройки → Приложения → Chrolingo). Имя файла с номером нужно
затем, чтобы старый и новый APK нельзя было перепутать в загрузках. Чтобы
скрипт не трогал установку даже при подключённом телефоне:
`NO_ADB=1 ./tools/build.sh features`.

`build.sh` останавливается на любой осечке: грязное дерево, разошедшаяся
ветка, упавшая сборка, APK без метки коммита. Ручная последовательность из
пяти команд ни одну из них не замечает — упавший `flutter build` просто
оставляет на диске прежний `app-release.apk`, и его же ставят на телефон.

## Как убедиться, что на телефоне нужная сборка

Коммит зашит в `versionName` пакета, поэтому вопрос решается, не открывая
приложение:

```
adb shell dumpsys package com.chrolingo.app | grep versionName
```

Это единственная метка, видная СНАРУЖИ приложения. Она появилась потому,
что самым слабым местом оказалась не сборка, а установка: APK собирался
правильно и оставался лежать на диске, а на телефоне продолжала работать
прежняя версия — и снаружи это неотличимо от настоящей поломки.

## Метка внутри приложения

`build.sh` печатает коммит и вшивает его в APK через
`--dart-define=BUILD_ID`. В приложении он виден под заголовком экрана
«Одиночная Игра». Совпал с тем, что напечатал скрипт, — сборка та.

Сверить, не заходя в приложение:

```
ID=$(git rev-parse --short HEAD)
unzip -p build/app/outputs/flutter-apk/app-release.apk lib/arm64-v8a/libapp.so \
  | tr -d '\0' | grep -ac "$ID"
```

`tr -d '\0'` здесь обязателен: если метка попадёт в один строковый литерал
с кириллицей, Dart уложит её в снимок как UTF-16, и поиск по обычной строке
ничего не найдёт — хотя сборка при этом совершенно правильная.
