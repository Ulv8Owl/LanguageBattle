# CEFR phrase dataset — спецификация формата

Сгенерировано 2026-09-05. Файлов 18 + README + validate.py.

## Файлы

- `phrases_<LEVEL>_<lang>.txt` — 10 фраз, по одной на строку

LEVEL ∈ A1 A2 B1 B2 C1 C2 · lang ∈ en ru es

## Файлов с пояснениями больше нет

В датасете были `explanations_<LEVEL>_<lang>.txt` с заранее написанным
разбором каждого элемента. Их удалили: такой текст написан про РОДНУЮ
формулировку («в семь», а не "at seven") и ничего не знает о том, что
игрок сказал на самом деле. Разбор ошибок пишет языковая модель по факту
ответа и только для тех элементов, которые игрок сказал не так —
`supabase/functions/_shared/explainElements.ts`.

## Инварианты структуры

| Уровень | Предложений во фразе | Элементов во фразе |
|---|---|---|
| A1 | 2 | 6 |
| A2 | 3 | 9 |
| B1 | 4 | 12 |
| B2 | 5 | 15 |
| C1 | 6 | 18 |
| C2 | 7 | 21 |

Правило: ровно 3 элемента на предложение на всех уровнях.

## Разделитель элементов

`|` ставится сразу после последнего слова элемента; знак препинания, идущий следом,
относится к следующему элементу (или замыкает строку):

```
I usually| walk to work|, but today| I am taking the bus|. The weather| is really bad|.
```

Нумерация `<строка>.<элемент>`, обе части с 1. Элемент (2,4) = 4-й элемент 2-й строки.

## Межъязыковое выравнивание

Число элементов совпадает для en/ru/es в каждой строке; элемент N строки M покрывает
один и тот же смысловой кусок во всех трёх языках. Границы проведены по клаузам,
чтобы выравнивание переживало разницу в порядке слов.

## Валидация

`python3 validate.py` проверяет: наличие 18 файлов, 10 строк во фразовых файлах,
число предложений и элементов по уровню, паритет en/ru/es по каждой строке.

## Что стоит помнить при расширении датасета

- Тематика: разнообразный быт + работа, по одной теме на фразу.
- C1/C2 — естественная речь: ирония, недосказанность, проф. и разговорный контекст,
  без вычурности; C1/C2 должны быть полностью связны по смыслу и грамматике.
- Новые фразы удобнее писать сначала на EN с готовой разбивкой, затем переводить,
  сохраняя число элементов.
