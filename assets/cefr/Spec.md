# CEFR phrase dataset — спецификация формата

Файлов 18 фразовых + 36 с разборами, плюс README и validate.py.

## Файлы

```
phrases/<LANG>/phrases_<LEVEL>.txt                          18 файлов
explanations/<РОДНОЙ>-<ЦЕЛЕВОЙ>/explanations_<LEVEL>.txt    36 файлов
```

LEVEL ∈ A1 A2 B1 B2 C1 C2 · LANG ∈ EN RU ES ·
каталоги пар: EN-RU EN-ES RU-EN RU-ES ES-EN ES-RU

## Почему разборы разложены по парам, а не по языкам

Пояснение обязано знать сразу две вещи: на каком языке его читать (родной
язык игрока) и про какой язык оно вообще (тот, который игрок учит).
Раскладка по одному языку даёт только вторую половину — и ровно на этом
сломалась прошлая версия: игроку с парой ru→en показывали разбор РУССКОЙ
формулировки («в семь») вместо английской ("at seven").

Каталог называется РОДНОЙ-ЦЕЛЕВОЙ, в том же порядке, в каком пара задана у
игрока: `RU-EN` — текст по-русски про английский.

## Формат строки разбора

```
<фраза>.<элемент> «<текст элемента на ЦЕЛЕВОМ языке>» — <разбор>
```

Ёлочки держат ЯКОРЬ: validate.py сверяет его с файлом фраз посимвольно,
поэтому разбор не может незаметно уехать на соседний кусок. До игрока
доезжает только часть после « — »: сам текст элемента и так стоит
заголовком панели.

Внутри разбора слова изучаемого языка берутся в двойные кавычки
(`"at seven"`), и проверка требует хотя бы одной такой цитаты в строке.

Якоря подставляет `tools/cefr_explanations.py` — набирать их руками на
4860 строках означало бы гарантированные опечатки:

```
python3 tools/cefr_explanations.py skeleton A1 en          # пустая заготовка
python3 tools/cefr_explanations.py fill A1 ru en < bodies  # строки «1.1 текст»
```

## Что должно быть в разборе

Игрок только что ошибся и, скорее всего, не понимает ПОЧЕМУ правильно
именно так. Поэтому:

- текст — на родном языке игрока, слова изучаемого — в кавычках и ровно в
  той форме, в какой они стоят в эталоне;
- объяснять причину, а не правильный ответ: «нужно сказать "at seven"» —
  плохо, «время на часах идёт с предлогом "at", а "in" ставят перед
  длинными отрезками» — хорошо;
- разбор не обязан ограничиваться одним элементом: если форма этой части
  задана другой (согласование, время, порядок слов), про ту часть надо
  сказать тоже;
- контраст с родным языком — самое ценное: одна и та же английская форма
  для русскоговорящего и для испаноговорящего трудна по разным причинам,
  и объяснять надо именно причину.

## Инварианты структуры

| Уровень | Предложений во фразе | Элементов во фразе |
|---|---|---|
| A1 | 2 | 6 |
| A2 | 3 | 9 |
| B1 | 4 | 12 |
| B2 | 5 | 15 |
| C1 | 6 | 18 |
| C2 | 7 | 21 |

Правило: ровно 3 элемента на предложение на всех уровнях.

## Разделитель элементов

`|` ставится сразу после последнего слова элемента; знак препинания, идущий следом,
относится к следующему элементу (или замыкает строку):

```
I usually| walk to work|, but today| I am taking the bus|. The weather| is really bad|.
```

Нумерация `<строка>.<элемент>`, обе части с 1. Элемент (2,4) = 4-й элемент 2-й строки.

## Межъязыковое выравнивание

Число элементов совпадает для en/ru/es в каждой строке; элемент N строки M покрывает
один и тот же смысловой кусок во всех трёх языках. Границы проведены по клаузам,
чтобы выравнивание переживало разницу в порядке слов.

## Валидация

`python3 validate.py` проверяет: наличие всех 54 файлов, 10 строк во фразовых
файлах, число предложений и элементов по уровню, паритет en/ru/es по каждой
строке, сплошную и неповторяющуюся нумерацию разборов, совпадение якорей с
элементами целевого языка, наличие цитаты на изучаемом языке в каждом разборе
и язык самого текста по каталогу пары.

## Что стоит помнить при расширении датасета

- Тематика: разнообразный быт + работа, по одной теме на фразу.
- C1/C2 — естественная речь: ирония, недосказанность, проф. и разговорный контекст,
  без вычурности; C1/C2 должны быть полностью связны по смыслу и грамматике.
- Новые фразы удобнее писать сначала на EN с готовой разбивкой, затем переводить,
  сохраняя число элементов.
- Каждая новая фраза тянет за собой шесть новых разборов на каждый её элемент:
  по одному на пару. Написать их проще уровнями — сразу все шесть пар одного
  уровня, — пока разбивка фразы ещё в голове.
