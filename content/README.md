# content/ — источник слов для Тренировки

Здесь лежат исходники банка слов (`words_<уровень>.txt`) по языкам:
`content/<код языка>/words_a1.txt` и так далее для всех уровней
(a1, a2, b1, b2, c1, c2).

**Фраз здесь больше нет.** Они переехали в `assets/cefr` — там каждая
фраза разбита на элементы (для подсказок и поэлементной оценки) и к
каждому элементу написано пояснение. Формат и правила расширения —
`assets/cefr/README.md`, сборка — `tools/build_cefr.py`.

**Формат — одно слово на строку, без какой-либо разметки.** Строка N
любого языка — перевод строки N английского файла того же уровня. Порядок
строк и есть ключ соответствия, отдельного id у слова нет.

## Как добавить слово

1. Допиши слово новой строкой **в конец** `content/en/words_<уровень>.txt`.
2. Допиши перевод в конец `content/<lang>/words_<уровень>.txt` для
   **каждого** языка, у которого уже есть перевод на этом уровне.
3. Собери JSON, который реально читает приложение:

   ```
   python3 tools/build_content.py
   ```

4. Закоммить и `content/`, и обновлённые `assets/vocab/*.json` вместе.

## Правило «весь уровень или ничего»

Язык должен быть переведён **полностью** на уровне (все 1000 слов), либо не
быть переведён вовсе — частичный перевод не поддерживается
(`FlashcardBank.hasContentFor` считает язык готовым по принципу «есть хотя
бы одна строка → должны быть все»). Поэтому `tools/build_content.py`
**требует**, чтобы число строк языка на уровне точно совпадало с
английским, и падает с понятной ошибкой при несовпадении, а не сдвигает
переводы на одну позицию. Так же падает сборка при пустой строке внутри
файла.

## assets/vocab/*.json — генерируемый файл, руками не редактировать

`assets/vocab/*.json` — это то, что грузит приложение
(`RemoteContent`/`FlashcardBank`). Их пересобирает `tools/build_content.py`
из `content/`, руками их не трогают.

Проверить, не разошлись ли `content/` и `assets/`, ничего не переписывая:

```
python3 tools/build_content.py --check
```

## Проверка перевода обратным переводом

`tools/verify_translation.py` — сравнение исходного текста с его обратным
переводом через эмбеддинги многоязычной модели. Подробности запуска — в
`--help` и в docstring файла.
